# 🧮 Projeto Calculadora - FinançApp

## 📋 Descrição do Projeto
Este projeto consiste no desenvolvimento de um módulo básico de cálculos matemáticos para a startup fictícia **FinançApp**, focada em aplicativos de controle de finanças pessoais.

## 🎯 Objetivo da Atividade
Desenvolver a capacidade prática na construção, validação, testes unitários, refatoração, documentação técnica (JavaDoc) e versionamento de software com Git e GitHub.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Java
* **Ferramentas:** Visual Studio Code, Git, JavaDoc
* **Controle de Versão:** GitHub

## ➕ Explicação das Operações
O sistema realiza as seguintes operações através da classe `Calculadora`:
* **Soma (+)**
* **Subtração (-)**
* **Multiplicação (*)**
* **Divisão (/)** (com bloqueio para divisão por zero)
* **Operações Inválidas** (com tratamento de erro)

## 🌿 Versionamento
O projeto possui duas branches principais:
* `master` (ou `main`): Implementação inicial e testes.
* `Refatoracao`: Código otimizado e estruturado aplicando boas práticas.
